YSTI – Bản tiếng Việt

Cấu trúc:
- index.html: giao diện trang web
- style.css: định dạng giao diện
- java.js: câu hỏi, tính điểm, ghép kết quả và tương tác
- images/: ảnh nhân vật được tách từ dữ liệu ảnh nhúng trong HTML gốc

Cách chạy:
1. Giải nén toàn bộ thư mục.
2. Giữ nguyên cấu trúc thư mục và file.
3. Mở index.html bằng trình duyệt hoặc tải cả thư mục lên hosting tĩnh.

Lưu ý: Nội dung, điểm số, thuật toán ghép kết quả và thứ tự xáo trộn câu hỏi được giữ theo mã nguồn gốc; phần chữ giao diện, câu hỏi và mô tả kết quả đã được Việt hóa.
